Politique de confidentialité — CosmoNote

Dernière mise à jour : 29 mai 2026

1. Introduction

CosmoNote est une application de prise de notes avec synchronisation et partage. Cette politique décrit quelles données sont collectées et comment elles sont utilisées.

2. Données collectées

  • Adresse e-mail — utilisée pour l'authentification via Firebase Authentication.
  • Contenu des notes — titre, texte et couleur de vos notes, stockés dans Firebase Firestore pour la synchronisation entre appareils et le partage avec d'autres utilisateurs.
  • Identifiant utilisateur (UID) — généré automatiquement par Firebase pour identifier votre compte.
  • Données publicitaires — des identifiants techniques (par exemple identifiant publicitaire, adresse IP, informations appareil) peuvent être traités par Google AdMob pour l'affichage et la mesure des annonces.

3. Utilisation des données

Vos données sont utilisées exclusivement pour :

  • Vous authentifier et sécuriser l'accès à vos notes.
  • Synchroniser vos notes entre vos appareils.
  • Permettre le partage de notes avec les utilisateurs que vous désignez.

4. Partage des données

Vos notes ne sont partagées qu'avec les utilisateurs que vous autorisez explicitement. Nous ne vendons pas vos données personnelles. Certains identifiants techniques peuvent cependant être transmis à Google AdMob pour l'affichage et la mesure des publicités.

5. Stockage et sécurité

Les données sont stockées sur les serveurs Firebase (Google Cloud Platform), protégés par des règles de sécurité Firestore limitant l'accès aux seuls utilisateurs autorisés. Les données locales sont stockées dans une base SQLite sur votre appareil.

6. Code PIN

Si vous activez le code PIN, celui-ci est stocké localement sous forme de hash (SHA-256). Il n'est jamais transmis aux serveurs.

7. Suppression des données

Vous pouvez supprimer vos notes à tout moment depuis l'application. Pour supprimer votre compte et toutes les données associées, utilisez la page dédiée : Demande de suppression de compte.

8. Services tiers

  • Firebase (Google) — authentification et stockage cloud.
  • Google AdMob — affichage et mesure des annonces publicitaires.

9. Vos choix (publicité)

Vous pouvez limiter la personnalisation publicitaire dans les paramètres de votre appareil Android (section "Annonces").
